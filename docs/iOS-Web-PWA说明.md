# 课序 iOS Web / PWA

## 基线

本网站严格从 GitHub `v0.9.6-stable` 标签建立，Android 稳定版目录保持不变。

## 功能

- 首页当前/下一节课程与今日安排
- 周课表、列表课表、教学周切换
- 手动添加、编辑和删除课程
- WHCIBE 账号同步课表
- 按学期查询成绩，读取全部分页及已开放的分项成绩
- 成绩、课表和同步快照保存在当前浏览器
- 深色模式、主题色、紧凑卡片和玻璃效果
- 课程日历导出、课表海报、同步记录恢复
- 可添加到 iPhone 主屏幕并离线查看已保存数据

## 隐私与网络边界

Safari 无法直接跨域访问教务系统，因此网站使用同源后端完成单次转发。密码只存在于当前请求内，不写入浏览器、日志或数据库；请求结束后 `requests.Session` 会立即关闭。服务器不保存课表、成绩和同步记录。

## iPhone 安装

1. 使用 Safari 打开部署后的 HTTPS 地址。
2. 点击 Safari 底部“分享”。
3. 选择“添加到主屏幕”。
4. 从桌面的“课序”图标启动。

## 部署

项目根目录包含 `render.yaml`，可通过 Render Blueprint 部署为同源 HTTPS 网站。必须部署完整 FastAPI 服务，不能只把 `web-app` 放到 GitHub Pages，否则 WHCIBE 登录、课表和成绩查询无法工作。
